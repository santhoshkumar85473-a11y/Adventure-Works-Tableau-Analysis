 Adventure Works – Tableau Data Analysis

 📌 Project Overview

This project analyzes the Adventure Works dataset using Tableau to identify business trends, performance patterns, and key insights through interactive data visualizations.

 🎯 Objectives

- Analyze business and sales data
- Identify important trends and patterns
- Create interactive Tableau dashboards
- Convert data into meaningful business insights
- Support data-driven decision making

 🛠️ Tools Used

- Tableau
- Data Visualization
- Data Analysis
- Calculated Fields
- Filters
- Interactive Dashboards

 📊 Dashboard

The Tableau workbook contains interactive dashboards designed to explore the Adventure Works dataset and present key business insights visually.

 📁 Project File
